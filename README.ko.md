# FabAssure 사용 안내

**Change → Verify → Evidence → Review → Accept**

FabAssure는 제조 변경의 검증 기준, 근거, 독립 검토와 수락을 한 이력으로 연결합니다. 이 저장소에는 오프라인 샘플 제품의 소스, 테스트와 Windows 배포 스크립트가 있습니다.

![FabAssure 개요 화면](media/overview.png)

## 빠른 탐색

1. [시작 안내](README_FIRST_KO.md)에 따라 Windows x64 번들을 만들고 실행합니다.
2. **변경 관리**에서 기준·근거·결정 순서를 확인합니다.
3. **FabTrace**에서 사건, 영향 LOT, CAPA 및 효과성 이력을 확인합니다.
4. **설비 이력**에서 사건과 고장·수리 기록의 시간을 대조합니다.
5. **데모 정보**에서 샘플 데이터와 실행 범위를 확인합니다.

설계와 검증 근거는 [아키텍처](docs/architecture.md), [업무 흐름](docs/workflow.md), [검증](docs/validation.md), [한계](docs/limitations.md)에 있습니다. 실행 순서는 [데모 가이드](docs/demo-guide.md)를 참조하세요.
