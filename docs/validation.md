# 검증 결과

공개 정리 기준에서 고정 Node.js v24.19.0으로 원본 소스와 독립 공개본의 전체 테스트를 각각 실행했습니다. 두 실행 모두 **290/290 통과, 실패 0, 건너뜀 0**입니다. 정리 전 수락 기준은 289개였으며, 공개 문구 검증 1개를 추가했습니다.

집중 UI 테스트는 14/14 통과했습니다. 문구 갱신에 따른 테스트 단언만 바꿨고 저장된 상태값, 서버 게이트, DB 스키마와 감사 규칙은 변경하지 않았습니다.

Windows x64 portable 번들을 새로 구성하고 `verify-offline.cmd`의 5개 검사를 모두 통과했습니다: 38개 번들 파일 무결성, 고정 런타임, 제한된 외부 연결 거부, 루프백 자산, 샘플 변경 승인 흐름. 시작·종료·초기화 과정에서 SQLite 백업 생성도 확인했습니다.

실제 Google Chrome에서 개요, 데모 정보, 변경 등록과 상세, 설비 이력, FabTrace를 이동했습니다. 새 변경이 로컬 SQLite에 저장됐고 브라우저 콘솔 오류, 페이지 오류, 외부 요청은 각각 0건이었습니다. [개요 캡처](../media/overview.png)는 정리 후 화면에서 새로 촬영했습니다.

이 결과는 데모 환경의 검증입니다. 실제 MES·설비 연동, 사용자 인증, 공장 운영 승인 또는 PC 전체의 네트워크 격리를 증명하지 않습니다.
