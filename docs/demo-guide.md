# 데모 가이드

## 실행

1. [시작 안내](../README_FIRST_KO.md)에 따라 번들을 만들고 `verify-offline.cmd`를 실행합니다.
2. `start-fabassure.cmd`를 실행한 뒤 같은 PC의 Chrome에서 `http://127.0.0.1:4310`을 엽니다.
3. 왼쪽 **개요**에서 변경부터 승인까지의 단계와 대표 업무 흐름을 확인합니다.
4. **변경 관리**에서 기록을 열어 검증 기준, 연결된 근거, 검토·수락, 감사 이력을 살펴봅니다.
5. **FabTrace**에서 사건의 영향 LOT, CAPA, 효과성 확인과 재개 이력을 확인합니다.
6. **설비**에서 고장·수리와 AOI 시간선을 대조합니다. **데모 정보**에서 샘플의 범위를 확인합니다.

## 종료·초기화

서버를 실행한 콘솔에서 `Ctrl+C`로 종료합니다. 기록을 새 샘플로 교체하려면 종료 후 `reset-demo.cmd`를 실행합니다. 기존 DB는 `data/backups`에 백업됩니다. 브라우저 탭만 닫아서는 서버가 종료되지 않습니다.
