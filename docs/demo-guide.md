# 데모 가이드

## 실행

1. [시작 안내](../README_FIRST_KO.md)에 따라 번들을 만들고 `verify-offline.cmd`를 실행합니다.
2. `start-fabassure.cmd`를 실행한 뒤 같은 PC의 브라우저에서 `http://127.0.0.1:4310`을 엽니다.
3. **개요**에서 여섯 단계(변경 → 검증 → 근거 → 검토 → 수락 → 효과성)의 건수를 확인합니다.
4. **변경 관리**에서 R2 레시피 변경을 등록하고 화면의 **다음 작업**을 따라 진행합니다. 필요한 역할은 오른쪽 위 **현재 역할**에서 바꿉니다. 첫 검증은 정렬 편차 0.100 mm로 불합격하고, 재작업 개정에서 다시 검증합니다.
5. 수락 전에 요청자 역할로 바꾸면 **차단 사유**가 표시됩니다.
6. 수락 후 **효과성 확인**에서 평가합니다. 수락 직후 시각으로 평가하면 후속 LOT이 없어 데이터 부족이 됩니다. 후속 LOT이 쌓인 시각(예: `2026-08-23T12:00:00.000Z`)으로 평가하면 합격 판정을 볼 수 있습니다.
7. **영향 추적**에서 사건을 등록하고 봉쇄, LKG, 영향 범위 계산, 범위 검토, CAPA를 진행합니다.
8. **설비 이력**에서 정비 기록과 AOI 결함 발생 시각을 대조합니다. **데모 정보**에서 데이터 범위를 확인합니다.

## 종료·초기화

서버를 실행한 콘솔에서 `Ctrl+C`로 종료합니다. 기록을 새 샘플로 교체하려면 종료 후 `reset-demo.cmd`를 실행합니다. 기존 DB는 `data/backups`에 백업됩니다.
