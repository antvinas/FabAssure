# 알려진 한계

- 모든 생산·측정·AOI·설비·사용자 기록은 합성 정렬·AOI 공정의 샘플입니다. 실제 공장 데이터, MES 또는 설비와 연결되지 않습니다. 반도체 fab 공정을 구현한 것이 아니라, 변경 판단 모델을 합성 공정 위에서 검증한 것입니다.
- 역할 선택은 모의 작업자 전환이며 로그인, 전자 서명, 실사용 권한 관리가 아닙니다.
- `127.0.0.1`과 로컬 파일을 사용하는 Windows x64 데모입니다. 원격 다중 사용자 운영, 고가용성 또는 실제 공정 승인용으로 설계되지 않았습니다.
- 번들 검증기는 파일 무결성, 고정 런타임, 루프백 자산, 제한된 외부 연결 거부와 샘플 승인 흐름을 검사합니다. PC 전체의 네트워크 차단이나 OS 방화벽 상태를 증명하지 않습니다.
- 샘플의 수치·위험 규칙·조건부 수락 기한은 실제 회사 정책이나 업계 기준이 아닙니다. 실제 운영 결정에 사용하지 마세요.
