# 아키텍처

FabAssure는 한 PC에서 실행하는 로컬 웹 앱입니다.

```text
브라우저 UI (assets/ui)
    ↓ 127.0.0.1 HTTP
로컬 서버 (src/server)
    ↓
도메인 규칙 (src/domain) ── SQLite 저장·마이그레이션 (src/data)
```

브라우저는 표시와 입력을 맡습니다. 상태 전이, 역할 분리, 수락 만료, 근거 적합성, 종결과 재개 판정은 서버/도메인에서 다시 검사합니다. 결정·개정·감사 이력은 저장되며 이전 결정을 덮어쓰지 않습니다.

앱은 `127.0.0.1:4310`에 바인딩하고 UI 자산을 로컬에서 제공합니다. 번들은 고정된 Node.js v24.19.0 실행 파일과 라이선스를 포함합니다. 원격 API, CDN, 원격 DB나 제품 실행 중 외부 AI 서비스가 필요하지 않습니다.

`src/data/schema-v*.sql`과 마이그레이션은 기존 기록을 보존합니다. 조건부 수락에는 명시적인 UTC 만료 시각이 필요하고, 유형을 판별할 근거가 없는 과거 수락은 분류 확인 전까지 현재 운영 승인으로 사용하지 않습니다.
