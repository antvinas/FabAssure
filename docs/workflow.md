# 업무 흐름

## 변경 검증

요청자가 변경을 등록하면 위험 수준과 검증 계획을 정하고, 승인된 기준에 측정·AOI 근거를 연결합니다. 증거 준비 후 별도 검토자와 승인자가 각자의 결정을 남깁니다. 불합격이나 재작업은 이전 개정과 근거를 보존한 새 개정으로 이어집니다.

조건부 수락은 승인자가 조건과 UTC 만료 시각을 명시합니다. 만료 시각부터는 현재 운영 승인으로 사용할 수 없습니다. 일반 수락에는 이 만료 규칙을 자동 적용하지 않습니다. 과거 유형 미상 수락은 조회 가능하지만 분류 확인 전에는 관련 운영 게이트를 통과하지 못합니다.

## 영향 추적과 CAPA

사건은 발견, 봉쇄, 마지막 정상 관측(LKG), 영향 LOT 계산과 독립 범위 검토를 거칩니다. CAPA 사이클에서는 원인, 조치, 별도 검토, 관리 문서 피드백과 승인을 기록합니다. 후속 LOT·AOI 원천 근거로 효과성을 확인하며, 종결과 재개는 이전 확인·결정을 보존합니다.

화면의 역할 선택은 흐름을 살펴보기 위한 모의 역할입니다. 실제 사용자 인증이나 전자 서명을 뜻하지 않습니다.
