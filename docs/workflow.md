# 업무 흐름

FabAssure의 제조 변경은 **변경 → 검증 → 근거 → 검토 → 수락 → 효과성** 여섯 단계로 진행합니다. 각 단계의 결정은 서버가 다시 검사하고, 이전 결정은 덮어쓰지 않습니다.

## 1. 변경

요청자가 대상 설비·모듈·레시피와 변경 이유를 등록하고 제출합니다. 품질 엔지니어가 심각도·발생도·검출도·범위와 핵심 특성·안전 영향으로 위험 수준(L1–L3)을 분류하고, 측정 전에 검증 계획과 합격 기준을 승인합니다. L3 계획은 요청자와 다른 품질 엔지니어가 승인합니다.

## 2. 검증

검증 엔지니어가 검증을 시작하고 변경 전 기준 LOT을 연결합니다. 기준(정렬 편차 ≤ 0.08 mm, AOI 불량률 ≤ 2 %, 중대 결함 0건)은 승인된 계획의 값으로만 판정합니다. 불합격이면 변경은 재작업 필요 상태가 되고, 요청자가 새 개정을 시작합니다. 불합격한 개정과 근거는 그대로 남습니다.

## 3. 근거

측정·AOI 원천 기록만 근거로 연결합니다. 변경 후 LOT은 검증 시작 이후의 실행이어야 하고, 연결한 근거는 원천 값과 검증값을 함께 저장합니다. 모든 기준이 판정되면 근거를 확정합니다.

## 4. 검토

독립 검토자가 확정된 근거를 검토합니다. 요청자와 근거를 기록한 사람은 같은 개정을 검토할 수 없습니다.

## 5. 수락

승인자가 일반 수락 또는 조건부 수락을 기록합니다. 요청자, 근거 기록자, 검토자는 수락할 수 없습니다. 조건부 수락에는 조건과 UTC 만료 시각이 필요하며, 만료 후에는 운영 승인으로 쓰지 않습니다. 유형이 기록되지 않은 과거 수락은 승인자가 분류하기 전까지 운영 판단에 쓰지 않습니다.

## 6. 효과성

수락 후 후속 LOT·공정 실행·AOI 기록으로 판단이 유지되는지 확인합니다. 후속 LOT이나 확인 기간이 부족하면 **데이터 부족**으로 남고 종결할 수 없습니다. 합격한 최근 확인이 있을 때 평가자·요청자와 다른 사람이 종결합니다. 이후 불합격 확인이 나오면 품질 엔지니어가 재개하며, 이전 수락·확인·종결은 이력에 남습니다.

## 영향 추적과 CAPA

이상이 발견되면 사건을 등록하고 봉쇄, 마지막 정상 관측(LKG), 영향 범위 계산, 독립 범위 검토를 거칩니다. 영향 LOT은 확정 영향·노출 가능·불확실·제외로 분류되며, 불확실한 LOT의 처분은 검토자가 LOT마다 이유와 함께 결정합니다. 이후 CAPA 사이클에서 원인, 조치, 독립 조치 검토, 관리 문서 피드백과 승인을 기록하고 후속 LOT으로 효과성을 확인합니다.
